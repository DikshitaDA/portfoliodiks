# Personal Developer Portfolio

A responsive, modern personal portfolio website built to showcase my software projects, technical skills, certifications, and experience.

## Live Demo

- Live Site: https://portfoliodiks.netlify.app
- GitHub Repository: https://github.com/DikshitaDA/portfoliodiks

## Built With

- Core Technologies: HTML5, CSS3, Bootstrap,JS
- Styling and Layout: Modern CSS Flexbox, Grid, Responsive Media Queries
- Hosting: Netlify

## Features

- Project Showcase: Interactive cards featuring live demo links and GitHub repositories.
- Skill Matrix: Categorized overview of programming languages, tools, and frameworks.
- About Me and Timeline: Narrative on academic background, interests, and engineering goals.
- Contact Form: Integrated communication channel for recruiters and collaborators.
- Mobile-First Design: Optimized across desktop, tablet, and mobile screens.

## Local Setup

1. Clone the repository:
git clone https://github.com/DikshitaDA/portfoliodiks.git
cd portfoliodiks

2. Run locally:
Open index.html directly in your browser.
